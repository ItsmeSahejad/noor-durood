# Language architecture

Planned locale paths: `/en/`, `/ar/`, `/ur/`, `/hi/`, `/bn/`, `/id/`, `/ms/`, `/tr/`, `/gu/`, `/fa/`.

Arabic, Urdu and Persian pages must set `dir="rtl"`. Each locale will receive its own title, description, Open Graph metadata, canonical URL and hreflang links. The current selector saves a session preference and demonstrates RTL layout; translation files are intentionally not published until reviewed by native speakers.
